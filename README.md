# 🎮 Ligation 4

Um MiniGame simples chamado Ligation onde o objetivo é ligar 4 peças do mesmo jogador na mesma direção, seja horizontal, vertical ou diagonal, onde cada jogada só pode ser feita na ultima linha disponível da coluna escolhida.

Me inspirei a criar esse projeto depois de assistir o jogo Road96 que tem esse MiniGame em sua história e achei um bom desafio 'recriar' em um projeto web.

## 🚀 Tecnologias 
- React
- TypeScript
- TailwindCSS
- Vite

## 🖥️ Acessar o projeto

Você pode acessar o projeto no seguinte site: [lig-4-virid.vercel.app](https://lig-4-virid.vercel.app)

Ou clonar o repositório localmente com git e executar o projeto local com os seguintes comandos:

O projeto vai ser executado em [http://localhost:3000](http://localhost:3000) por padrão.

```bash
git clone https://github.com/matheusdsilva01/ligation.git
cd ligation
npm install
npm run dev
```
